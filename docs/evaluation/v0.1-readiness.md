## Dependency review

`cargo deny check` passed advisories, bans, licenses, and sources. It reported
warning-level duplicate versions of `bitflags`, `syn`, and `windows-sys`.
Those duplicates come from the maintained upstream stacks for `lsp-types`,
`notify`, `rmcp`, `clap`, and platform support; Chakra does not select the
duplicate versions directly.

Every production dependency has a current v0.1 responsibility: atomic
publication (`arc-swap`), typed contracts/errors (`serde`, `schemars`,
`thiserror`), bounded text/syntax intelligence (`regex`, Tree-sitter), native
watching (`notify`), CLI/MCP/runtime/logging (`clap`, `rmcp`, `tokio`,
`tracing`, `tracing-subscriber`), or the isolated rust-analyzer adapter
(`crossbeam-channel`, `lsp-server`, `lsp-types`, `url`, `serde_json`). No direct
production dependency was removed because the review found no unused or
unjustified entry.

The same resource review replaced post-hoc Git output length checks with
streaming bounded capture: repository discovery retains at most 64 MiB and the
worktree diff adapter at most 8 MiB while still draining child-process pipes.
