# Rust language support

Status: first-class (see `docs/support/languages/rust.json` and
`docs/language-parity-contract.md`). Selection record: ADR-0027.

## What is supported

- Git-aware discovery of tracked and untracked non-ignored `.rs` files.
- Cargo-aware project scopes and language-neutral source roles
  (production/test, ADR-0019).
- Tree-sitter syntax intelligence (`tree-sitter-rust 0.24`): declarations,
  nested containers (`mod`, `impl`, traits), imports/aliases, byte-accurate
  ranges, `#[test]`/`#[cfg(test)]` test hints, actionable syntax diagnostics
  (ADR-0022), and bounded lazy syntax call candidates (ADR-0010).
- Precise enrichment through rust-analyzer (optional, on demand):
  definitions, references, and callers with revision-scoped synchronization
  (ADRs 0006, 0013).
- All seven Chakra queries (`status`, `repo_map`, `search`, `symbol_search`,
  `context`, `callers`, `diff_context`) and their MCP exposure, with atomic
  revisions, `require_fresh`, provenance/precision, ambiguity reporting,
  budgets, truncation, and cancellation.

## Install and runtime requirements

- **Syntax intelligence** (always available): none. The grammar is compiled
  into Chakra; indexing runs fully offline.
- **Precise enrichment** (optional): a `rust-analyzer` binary on `PATH`
  (e.g. `rustup component add rust-analyzer`). Chakra owns the process
  lifecycle: bounded readiness, restart with backoff, cancellation, and
  shutdown without orphan processes. When rust-analyzer is absent, crashed,
  or not ready, queries degrade to syntax intelligence with explicit
  provenance — nothing fails.

## Measured limitations

From the pinned public corpus evaluation (`docs/support/corpus/RESULTS.md`,
macOS/aarch64, 2026-08-18, release build):

- `tokio-rs/tokio` (793 source files): cold index ≈ 0.49 s, peak RSS
  ≈ 124 MiB, 16 888 symbols / 19 117 edges, warm no-op ≈ 90 ms.
- `BurntSushi/ripgrep` (110 source files): cold index ≈ 0.18 s, peak RSS
  ≈ 211 MiB, warm no-op ≈ 65 ms.

Known limitations:

- Syntax call candidates are heuristic at call-site level; exact overload and
  macro-generated code resolution requires rust-analyzer enrichment.
- Macro expansions are not evaluated by the syntax layer; declarations
  generated by macros may be absent from the syntax graph.
- rust-analyzer startup on very large workspaces is bounded by the readiness
  budget (ADR-0013); queries during warmup answer with syntax provenance.
- Cancellation is asserted with pre-cancelled tokens in the corpus harness;
  mid-flight cancellation coverage is a recorded follow-up (ADR-0029).
